# Architecture Decision Records

Ogni ADR registra una decisione non ovvia: contesto, decisione,
conseguenze, alternative scartate. Diverse decisioni qui correggono la
scelta ingenua emersa in revisione critica: non vanno regredite.

Formato: Status, Contesto, Decisione, Conseguenze, Alternative scartate.
